# Physical Balatro Recreation (WIP):
A recreation of Balatro using Python, Arduino, Computer Vision, Servos, and Epaper

# TECHNICAL FEATURES:
- Complex state management
- Computer vision via OpenCV ArUco detection
- Low latency handshake serial communication
- Use of Epaper tags to dynamically modify a physical card's state
- Communication with many servos via PWM
- Multiplexing OLEDs
